# Known issues archive: full rows before the 2026-10-17 trim

`docs/KNOWN_ISSUES.md` passed 86 KB, so DX2 cut each long row to its issue, class and the note that matters, and kept
about 300 characters a row. This file holds those rows as they stood on 2026-10-16, word for word: the measurements,
seed counts and history behind each. Grep it for an issue's first words; do not edit it. KI2 (merged on 2026-10-17)
changed some owner tags and deleted four rows; those changes are applied here too.
