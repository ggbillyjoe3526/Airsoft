## Decisions

- **A replica's model file draws in the game's own replica materials, mapped from its material names.** So Realistic colours, the glow and the High finish (speckle, edge highlight) apply exactly as on the built-in models, and the file needs no textures.
- **Only pistols take a file for now.** The pistols share one grip line, hold and support hand; a rifle needs its own build path (handguard holds, barrel extensions, sights), left for the next model task.
- **The figures' version is the file's `Figure` object, placed in the figures' pistol frame from the file** (the back of the slide at the origin, the bore on the axis), so the figure's hands and torch need no new numbers.
- **The orange-tip setting adds a disc over the file's plain muzzle** (REPLICA_FILE.orangeTip), so the model stays plain and the setting keeps working.
- **The weapon torch still draws from the built-in layout;** the file's `TorchMount` marker is read and lies inside that clamp's span, ready for a file-driven torch later.
