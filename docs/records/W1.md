## Decisions

- **WebGPU is the default renderer, behind no Dev setting (owner, 2026-10-08).** Auto draws with WebGPU wherever the
  probe finds a hardware adapter and with the old WebGLRenderer otherwise; plain materials on WebGPU until W2–W4 are
  accepted, because releases wait for the whole overhaul. (DECISIONS line owed by the docs thread.)
- **The owner skipped the W0 laptop and desktop baselines (2026-10-08).** WebGPU is judged on the container's counts
  (draws, triangles, memory) and his playtests; the Renderer row is his way back to WebGL.
- **Under Auto a software adapter (`isFallbackAdapter`) counts as no WebGPU.** A software WebGPU would be far slower
  than the WebGL path; an explicit WebGPU pick may still use it.
- **`three/webgpu` loads only by dynamic import after the probe finds an adapter.** The main chunk grows 2 kB (945,957
  of 950,000 bytes) and WebGL-only browsers never download it.
- **A device lost on the node path is replaced; when no new device can be made, WebGL takes over until the next load.**
  The post stack, sheen and retro filter come back and the row says what happened.
- **On the node renderer an antialiasing change applies from the next load.** `replaceContext` returns false and
  `antialiasPending` reports it, as REN-04 already allows.
