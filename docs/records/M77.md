## Decisions

- **A character still exactly where its last ground probe set it down is not probed again (also in DECISIONS).** In two
  seeded 90 s matches about 39 % of probes were a character standing on its settled spot, where a fresh cast moved it
  by 2 µm on average (at most 0.8 mm) and never lost the ground. Sim alone, standing: Depot 92 → 64 µs a tick, Woodland
  143 → 83, Neon Heights 147 → 82 (median, measured in the order that penalises the skip).
- **The controller's own "grounded" is not the shortcut, so acceptance 2 is met by the rest memo instead.** The task's
  suggestion (skip when the mover found the ground that tick) moved controller-grounded characters by up to 4 cm on
  slopes (about 2.7 mm a tick on average on Woodland), which breaks the criterion's "movement unchanged".
- **`length3` (`sim/vec.ts`) or `Math.sqrt` on every per-tick and per-frame path; build-time code keeps `Math.hypot`
  (also in DECISIONS).** natureShapes, replicaFinish, surfaceNormals and vertexOcclusion run once at load.
- **The BB renderer writes its instance matrices straight into the instance arrays.** Calls with number arguments box
  them in V8 (`Matrix4.setPosition`, `makeScale`), which was most of the 7.9 KB a frame; the untouched cells keep the
  identity InstancedMesh starts with. BB renderer, dust motes and flag cloth now measure 0 B a frame in Node.
- **The extraction guard test finds a wide, square wall along the axes.** With the probe skip the guard stood a few µm
  differently and slid off the end of the wall the old oblique search had found; the new search is exact either way.
