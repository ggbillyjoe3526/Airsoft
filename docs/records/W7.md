## Decisions

- **The pictures are drawn on WebGPU**, the back end most players get, through the container's SwiftShader Vulkan adapter (`webgpuCompare.mjs` `WEBGPU_ARGS`); `--backend webgl` draws them on the WebGL2 back end, and each page refuses a still drawn on the other.
- **A WebGPU canvas is read back as a PNG.** Drawing it straight into a 2D canvas copied black on SwiftShader's adapter (the first backdrop came out a 1.5 kB black frame); its `toDataURL` holds the frame.
- **A still waits for a settled frame.** The game's loop stops, then frames from the stood camera until the draw count holds three in a row and eight more for the temporal pass, as `webgpu-compare.mjs` settles its views; the counts sit in the script (`STILL_SETTLE`), as no game code reads them.
- **A black read-back is refused**, and `config/menuArt.test.ts` pins each shipped picture's size, budget and a 4 kB floor, and that `public/menu/` holds only the listed pictures.
- **The cameras (`STILL_CAMERA`) are kept.** Every view still frames its map, Woodland's 5v5 layout included; its still shows the GPU grass and tree stand-ins.
- **The id W7** follows W6 in the WebGPU steps (ROADMAP's "Map pictures" row).
