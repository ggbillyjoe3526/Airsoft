# Patch notes

The release notes of each tag, as published on GitHub: one file per tag, such as `0.1-dev.4.md`.
The changelog agent writes each one when the owner tags a release (`.claude/agents/changelog.md` › On a release).
One correction to the published text: `0.1-dev.4.md` names the MIT licence, which `LICENSE` holds, where the GitHub
release said PolyForm Noncommercial.
