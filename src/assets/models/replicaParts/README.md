# Replica parts

A replica's fittable parts as `<replica id>.glb` (glTF binary): the AEG's and the gas pistol's (RM1). Each part is
one top-level object named `<kind>_<id>` (`optic_redDot`, `magazine_hiCap` …) in the replica's space where it fits; a
part a file lacks is drawn built-in. How to make them: [docs/CC0_ASSETS.md](../../../../docs/CC0_ASSETS.md) › Replica
models. Record every file in [docs/ASSETS.md](../../../../docs/ASSETS.md).
