# Character models

Drop the player and bot model here as `figure.glb` (glTF binary). The game picks it up when it's built or the dev
server starts; without it the built-in figures are drawn. Node names, team colours, scale, the size budget and
where to find CC0 models: [docs/CC0_ASSETS.md](../../../../docs/CC0_ASSETS.md). Record every model in
[docs/ASSETS.md](../../../../docs/ASSETS.md).
