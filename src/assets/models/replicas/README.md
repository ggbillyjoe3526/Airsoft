# Replica models

A replica's model as `<replica id>.glb` (glTF binary): `cyber.glb` is the Cyber Pistol's (M101). The game loads every
file here at start and draws that replica from it in the hands, on the menus' pictures and on the figures; without one,
or with one it can't use, the built-in model is drawn. Objects, materials, space and budget:
[docs/CC0_ASSETS.md](../../../../docs/CC0_ASSETS.md) › Replica models. Record every model in
[docs/ASSETS.md](../../../../docs/ASSETS.md).
