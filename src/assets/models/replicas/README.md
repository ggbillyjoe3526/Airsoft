# Replica models

A replica's model as `<replica id>.glb` (glTF binary): the AEG's, the gas pistol's and the Cyber Pistol's (M101, RM1),
with their fittable parts beside them in `../replicaParts/<replica id>.glb`. The game loads every file at start and
draws that replica from it in the hands, on the menus' pictures and on the figures; without one,
or with one it can't use, the built-in model is drawn. Objects, materials, space and budget:
[docs/CC0_ASSETS.md](../../../../docs/CC0_ASSETS.md) › Replica models. Record every model in
[docs/ASSETS.md](../../../../docs/ASSETS.md).
